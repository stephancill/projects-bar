# Project Instructions

- This is a native macOS menu bar app written in Swift/AppKit.
- Keep the app dependency-free unless a dependency is clearly justified.
- Before making changes, check `docs/implementation-notes.md` for current behavior and assumptions.
- When making implementation changes, update `docs/implementation-notes.md` before committing if the behavior or architecture changes.
- Prefer small, direct changes over broad abstractions.
